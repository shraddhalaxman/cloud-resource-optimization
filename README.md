# ☁️ Cloud Resource Optimization Automation

##  Overview

Cloud environments can contain virtual machines that are no longer actively used but continue consuming infrastructure resources.

This project focuses on identifying potentially unused VM instances and generating deletion recommendations to help improve cloud resource utilization.

## Objective

- Identify potentially unused VM instances
- Analyze VM usage information
- Generate recommendations for resources that may no longer be required
- Support better cloud resource utilization
- Reduce unnecessary infrastructure consumption
